# Hardware

| Part | Notes |
|------|-------|
| Raspberry Pi 5 (16 GB) | Runs the app. Quad-core Cortex-A76, Debian 13 (trixie), 64-bit. |
| 3.5" IPS capacitive touch display, 320 x 480 | Driver ST7796S over SPI. Touch controller FT6336U over I2C. Multi-touch. About 63 mA at 3.3 V. |
| Official Raspberry Pi 5 case | Includes a PWM fan and heatsink. |
| Raspberry Pi 27 W USB-C power supply | 5.1 V / 5 A. |
| MicroSD card | Holds the OS and the app. |

The display is the 3.5" IPS module from The Pi Hut. Its pinout is in [wiring.md](wiring.md).
